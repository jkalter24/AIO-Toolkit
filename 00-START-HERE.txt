## 💡 USE CASES

### Use Case 1: System Softlocking Investigation
```
Symptom: System freezes every 10-30 minutes
Suspected Cause: GPU driver or storage timeout

What to do:
1. Run "Run Full Diagnostics"
2. Check "GPU TDR Events" tab (if >1, it's GPU)
3. Check "Storage Timeouts" tab (if >1, it's storage)
4. Check SSD temps in "SSD Health" tab
5. Apply "Windows Repair" + review GPU driver version
6. Rerun after 24 hours
```

### Use Case 2: Unexpected Reboots
```
Symptom: System crashes to reboot without warning

What to do:
1. Run "Run Full Diagnostics"
2. Check "Reboot Events" tab (frequency indicator)
3. Check "WHEA Errors" tab (hardware faults?)
4. Check top issue in "Overview"
5. If >5 WHEA: Update BIOS and check RAM
6. If >2 TDR: Update GPU driver
7. If >2 timeouts: Monitor SSD health
```

### Use Case 3: Monthly Maintenance
```
Symptom: Preventive maintenance

What to do:
1. Run "Run Full Diagnostics" once per month
2. Save results to baseline folder
3. Compare against previous month
4. Trends indicate emerging issues
5. Address issues before they become critical
```

### Use Case 4: Pre-Upgrade Validation
```
Symptom: Want to upgrade hardware (GPU, RAM, SSD)

What to do:
1. Run "Run Full Diagnostics"
2. Check "SSD Health" (wear %, temps)
3. Check "WHEA Errors" (RAM health)
4. Note GPU driver version
5. Use as baseline for post-upgrade comparison
```

## 📊 DIAGNOSTIC SECTIONS EXPLAINED

### 1. System Snapshot (< 5 seconds)
Captures: OS version, CPU, RAM, BIOS, GPU, volumes
Shows: Your hardware configuration baseline

### 2. Windows Integrity (10-15 minutes)
Runs: SFC, DISM checks
Finds: Corrupt OS files, component store damage
Repairs: Rebuilds damaged components

### 3. SSD & Storage Health (< 1 minute)
Checks: SMART data per drive
Finds: Temperature, wear %, read/write errors
Shows: Your D: spanned drive status individually

### 4. Disk Checks (1-5 minutes per drive)
Runs: chkdsk /scan, fsutil dirty query
Finds: Filesystem errors, pending repairs
Note: Doesn't repair (-f flag would require restart)

### 5. Event Log Analysis (1-5 minutes)
Scans: Last 30 days of system events
Finds:
- WHEA (hardware) errors
- TDR (GPU timeout) events
- Storage controller issues
- Unexpected reboot/crash logs

### 6. Drivers & Firmware (< 1 minute)
Lists: All signed device drivers
Checks: GPU driver age, BIOS age
Recommends: Updates if >6 months old

### 7. Performance Snapshot (< 1 minute)
Shows: Top 15 CPU consumers, top 15 memory consumers
Helps: Identify resource hogs

### 8. Diagnostic Scoring (< 1 minute)
Weighs: All findings against known issue patterns
Ranks: Categories by severity (Storage, GPU, Memory, etc.)
Result: "Most likely culprit" + detailed reasons

### Scenario: System crashes every 2 minutes
```
FASTEST PATH TO DIAGNOSIS:
1. Open PowerShell as Administrator
2. Change to the folder where you saved the scripts (e.g. your Downloads folder)
  Example: `cd "C:\Path\To\Scripts"`

6. Look at "Most likely culprit:"

   → If Storage: Back up data
```

## 🎓 LEARNING RESOURCES

### Understanding Your Diagnosis
- Read: Cipher-System-Check-v7-README.md
- Search: Your top issue + "Windows 10"
- Example: "GPU TDR events Windows 10" + search

### Understanding Event Codes
- Event ID 41: Kernel-Power (crash)
- Event ID 6008: Unexpected shutdown
- Event ID 4101: GPU/Display error
- Event ID 129-161: Storage/NTFS errors
- WHEA events: CPU/Memory/Firmware issues

### Understanding SMART Data
- Temperature <45°C: Good
- Temperature 45-55°C: Monitor
- Temperature >55°C: Overheating (investigate cooling)
- Wear <20%: Normal (SSD lifespan ~5 years typical)
- Wear 20-80%: Working normally
- Wear >80%: End of life approaching
- Read/Write Errors >0: Imminent failure
