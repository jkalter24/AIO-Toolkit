# Cipher System Check v7 - Quick Reference Card

## 🚀 QUICK START (30 seconds)

1. **Right-click** `Cipher-System-Check-v7-Launcher.bat` → **Run as Administrator**
2. Wait for GUI to open
3. Click **"▶ Start Full Scan"** button
4. ☕ Grab coffee (5-15 min runtime)
5. Review tabs for findings

## 🎯 WHAT EACH DIAGNOSTIC FINDS

| Diagnostic | Finds | Severity |
|-----------|-------|----------|
| **SSD Health** | Drive temps, wear %, errors | High |
| **WHEA Errors** | RAM/CPU/firmware faults | Critical |
| **GPU TDR** | Driver hangs, timeouts | High |
| **Storage Timeout** | Controller issues, drive failures | High |
| **Reboots** | Crashes, power cycles | Critical |
| **Windows** | Update issues, OS corruption | Medium |
| **Drivers** | Old drivers, missing updates | Medium |
| **Firmware** | Old BIOS, instability | Low-Medium |

## 🔧 REPAIR OPTIONS - QUICK GUIDE

| Repair | What | Safety | When | Time |
|--------|------|--------|------|------|
| **Windows** | Fix update cache, component store | ✅ Safe | If errors shown | 15m |
| **GPU Tweak** | Increase TDR delay | ⚠️ Medium | If TDR events | 1m |
| **Network** | Reset TCP/IP, Winsock | ⚠️ Medium | If network issues | 1m |
| **Memory Diag** | Test RAM | ⚠️ Requires restart | If WHEA errors | 20m |
| **Defender** | Full malware scan | ⚠️ Slow | Good practice | 30-60m |

**TL;DR**: Start with "Windows Repair" if unsure.

## 🟢 GOOD SIGNS (Normal)

- **SSD Temps**: 30-45°C
- **SSD Wear**: 0-5%
- **SSD Errors**: 0 read/write errors
- **WHEA Events**: 0-2 total (30 days)
- **TDR Events**: 0-1 total
- **GPU Driver Age**: <180 days
- **Unexpected Reboots**: 0 in 30 days
- **BIOS Age**: <2 years

---

## 🟡 YELLOW FLAGS (Investigate)

- **SSD Temps**: 45-55°C → Check cooling
- **SSD Wear**: 5-20% → Normal aging
- **WHEA Events**: 3-10 → Update BIOS, check RAM slots
- **TDR Events**: 2-5 → Update GPU drivers
- **GPU Driver Age**: 180-365 days → Update soon
- **Unexpected Reboots**: 1-2 → Monitor, run repairs
- **BIOS Age**: 1-2 years → Check manufacturer website

---

## 🔴 RED FLAGS (Act Now)

- **SSD Temps**: >55°C sustained → Risk of failure
- **SSD Wear**: >80% → Drive is failing
- **SSD Errors**: Any read/write errors → Imminent failure
- **WHEA Events**: >10 → Hardware issue
- **TDR Events**: >5 → GPU driver/hardware problem
- **Unexpected Reboots**: >2 → System instability
- **Storage Timeouts**: Any → Spanned drive at risk

## 📊 SAMPLE OUTPUT INTERPRETATION

### Example: High GPU Score

```
GPU: 40 points
├─ Display-driver reset/crash pattern (3 TDR events)
├─ GPU driver older than 180 days
└─ NVIDIA display-driver evidence present
```

**Translation**: Your GPU driver is hanging. Update it.

**Action**: 
1. Visit https://www.nvidia.com/Download/driverDetails.aspx
2. Search for GTX 1060
3. Download latest driver
4. Install and reboot
5. Re-run diagnostics

### Example: High Storage Score

```
Storage: 35 points
├─ Media errors on: SSD0, SSD1
├─ Storage controller timeout pattern detected
└─ High storage event volume (25 events)
```

**Translation**: Your SSDs are failing.

**Action**:
1. Back up data immediately
2. Replace failing drive
3. Rebuild spanned volume
4. Re-run diagnostics

## 🆘 EMERGENCY ACTIONS

### If System Softlocks Every Few Minutes
```powershell
# Fast diagnostics without heavy scanning
.\Cipher-System-Check-v7.ps1 -Mode Core -QuietMode
# Don't apply repairs yet; just identify the issue
```

### If You Suspect GPU Driver
```powershell
# Update GPU driver to latest version
# Nvidia: https://www.nvidia.com/Download/
# AMD: https://www.amd.com/support
```

### If You Suspect WHEA / RAM
```powershell
# Run memory test (requires reboot)
.\Cipher-System-Check-v7.ps1 -Mode Core -RunMemDiag
# Or manually: mdsched.exe
```

### If You Suspect Storage
```powershell
# Run disk check (can take hours on spanned drive)
chkdsk D: /scan
# Check each SSD individually if possible
```

## 📞 WHEN TO GET HELP

✋ **Stop and get professional help if:**
- S.M.A.R.T. shows media errors (drive failure)
- WHEA constantly shows CPU/memory errors (hardware defect)
- System still crashes after all repairs
- You're not comfortable with the findings

👍 **You're good to proceed if:**
- Results show driver/firmware issues (software fixable)
- Scores are <25 (minor issues)
- You understand what each repair does
